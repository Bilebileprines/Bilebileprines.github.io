## 网站特色 · Site Features

- **整页滚动章节** · 7 个章节，流畅的逐章节色彩过渡
- **情境感知光标** · 随章节切换形态（齿轮 / 树叶 / 油漆 / 铅笔）
- **滚动入场动画** · 元素随滚动淡入滑出
- **实时调试面板** · 无需改代码即可调整字体、过渡速度、网格密度、光标与噪点
- **噪点纹理叠加** · 全页胶片颗粒质感
- **响应式布局** · 适配桌面与平板设备
